# vEx - videoExtractor
Dicord bot that extracts and sends video from the given link

## Discord bot invite/installation link
```
https://discord.com/oauth2/authorize?client_id=1500124730286411946
```

## Working platforms
* Instagram
* TikTok

## Usage
* Right Click on anyone from your friend list
* From menu select Apps > vEx > requestDM
* Send him link to desired video
* *Voilà*
